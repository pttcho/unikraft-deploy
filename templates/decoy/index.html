Edge Sync Gateway

Stateless edge delivery · API v2

This host provides an edge synchronization endpoint for distributed clients. All connections are terminated at the edge and forwarded internally.

Endpoints

  • GET / — service status page
  • POST /api/v2/stream — bidirectional stream (requires upgrade)
  • POST /cdn/v1/sync — asset synchronization (requires upgrade)

Status

Operational. Edge nodes are healthy.

Notes

Stream endpoints require a valid protocol upgrade handshake. Plain HTTP requests to these paths are not supported and will be rejected by the transport layer.
